# 🌡️ Temperature Converter

## 📌 About the Project

The Temperature Converter is a simple web application built using **HTML**, **CSS**, and **JavaScript**. It allows users to convert temperatures between **Celsius**, **Fahrenheit**, and **Kelvin** instantly.

The application also validates user input and prevents temperatures below absolute zero, making the conversion accurate and user-friendly.

This project helped me practice JavaScript fundamentals, DOM manipulation, event handling, and form validation.

---

## ✨ Features

* Convert between Celsius, Fahrenheit, and Kelvin
* Instant temperature conversion
* User-friendly interface
* Input validation
* Absolute zero temperature validation
* Responsive and clean design
* Displays results in all three temperature units

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open **index.html** in your web browser.
4. Enter a temperature value.
5. Select the input unit.
6. Click the **Convert** button to view the converted temperatures.

## ⚙️ How It Works

1. Enter a temperature value.
2. Select the input unit (Celsius, Fahrenheit, or Kelvin).
3. Click the **Convert** button.
4. The application converts the temperature into all three units.
5. If the input is invalid or below absolute zero, an appropriate error message is displayed.
