# 💼 Personal Portfolio Website

## 📌 About the Project

This is my personal portfolio website built using **HTML** and **CSS**.

The website introduces me, showcases my skills, highlights my projects, and provides my contact information. It is designed with a clean, modern, and fully responsive layout so it looks good on both desktop and mobile devices.

This project helped me improve my frontend development skills and understand how to create a professional portfolio website.

---

## ✨ Features

* Responsive navigation bar
* Hero section with introduction
* About Me section
* Skills section
* Projects showcase
* Contact information
* Footer with social links
* Smooth scrolling
* Responsive design for mobile devices
* Modern dark theme

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure all images and the resume file are in the correct folders.
4. Open **index.html** in any web browser.
5. Explore the portfolio website.
