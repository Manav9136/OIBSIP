# 👟 Flex Shoes Landing Page

## 📌 About the Project

Flex Shoes is a modern and responsive shoe landing page built using **HTML** and **CSS**.

The website is designed to showcase a shoe brand with a clean layout, attractive design, and smooth user experience. It includes sections like featured products, customer reviews, about the brand, and a footer with contact information.

This project helped me practice responsive web design, Flexbox, CSS Grid, hover effects, and overall webpage layout.

---

## ✨ Features

* Responsive navigation bar
* Attractive hero section
* Featured shoes section
* About Flex section
* Customer reviews
* Footer with social links
* Hover animations
* Mobile responsive design
* Smooth scrolling

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts (Poppins)
